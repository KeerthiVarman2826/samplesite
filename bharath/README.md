# Sweet RIKE Bakery Website

A premium, responsive website for Sweet RIKE Bakery, showcasing their delicious baked goods with a modern and elegant design.

## Project Structure

- `index.html`: Main bakery website (in backary/ folder)
- `script.js`: JavaScript for interactivity (smooth scrolling, animations)
- `style.css`: Premium CSS with responsive design and animations
- `backary/`: Contains the complete bakery website

## Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile
- **Modern UI**: Clean, elegant design with warm color palette
- **Smooth Animations**: Hover effects, scroll animations, and transitions
- **Interactive Elements**: Smooth scrolling navigation, WhatsApp ordering
- **Premium Gallery**: Image gallery with zoom effects
- **About Section**: Bakery story and statistics
- **Contact Information**: Location, phone, email, and hours

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- JavaScript (ES6)
- Google Fonts (Poppins, Playfair Display)

## How to Run

1. Clone the repository
2. Open `backary/index1.html` in your web browser
3. For the best experience, serve it with a local server (e.g., using Python: `python -m http.server`)
